# Laboratorul 1 - Calculator IMC

Aplicație Flutter pentru calcularea indicelui de masă corporală (IMC).

## Funcționalități

- introducerea greutății în kilograme;
- introducerea înălțimii în centimetri;
- validarea valorilor introduse;
- calcularea indicelui de masă corporală;
- afișarea rezultatului și a categoriei corespunzătoare.

Formula utilizată este:

`IMC = greutate / înălțime²`

## Rulare

```bash
flutter pub get
flutter run
```

## Testare

```bash
flutter test
```
