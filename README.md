# PAM Laboratoare

Repository-ul conține proiectele Flutter realizate la disciplina Programarea Aplicațiilor Mobile.

- `Lab2` — interfața aplicației pentru programări medicale.
- `Lab3` — state management cu Cubit, încărcare asincronă din JSON, căutare, filtrare, sortare, favorite și navigare către detalii.

Fiecare laborator este un proiect Flutter separat și conține propriul fișier `pubspec.yaml`.
